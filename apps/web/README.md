# apps/web

React PWA (Vite, TypeScript, Tailwind). **Not yet implemented** (Phase 2).

Planned feature areas under `src/features/`: `capture`, `review`, `patient-summary`, `admin`.
The UI owns presentation, role-based views, the offline upload queue and i18n. It contains no
clinical logic or thresholds. STUB results must be visibly labeled.

Note: `src/` currently holds only placeholder folders. When scaffolding with Vite, keep
`src/features/`.
